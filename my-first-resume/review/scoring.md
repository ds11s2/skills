# 简历打分标准

## 总分构成

| 模块 | 满分 | 权重 |
|-----|------|------|
| 基本信息 | 15 | 15% |
| 教育背景 | 15 | 15% |
| 项目经历 | 25 | 25% |
| 实习经历 | 15 | 15% |
| 技能特长 | 10 | 10% |
| 自我评价 | 5 | 5% |
| 格式规范 | 10 | 10% |
| ATS 兼容 | 5 | 5% |
| **总计** | **100** | **100%** |

---

## 各模块详细打分标准

### 一、基本信息（15 分）

| 评分项 | 满分 | 评分标准 |
|-------|------|---------|
| 姓名清晰可见 | 3 | 有姓名且位置显眼得 3 分，姓名不明显得 1 分，无姓名得 0 分 |
| 电话号码 | 3 | 格式正确且可联系得 3 分，格式不规范得 1 分，无电话得 0 分 |
| 邮箱 | 3 | 专业邮箱得 3 分，QQ 邮箱得 1 分，无邮箱得 0 分 |
| 求职意向 | 3 | 岗位+城市明确得 3 分，仅岗位得 1 分，无得 0 分 |
| 链接 | 3 | 有相关链接得 3 分，无得 0 分 |

### 二、教育背景（15 分）

| 评分项 | 满分 | 评分标准 |
|-------|------|---------|
| 基本信息 | 5 | 四项完整得 5 分，缺 1 项得 3 分，缺 2+ 项得 1 分 |
| GPA/排名 | 3 | 有且优秀（≥3.5 或前 20%）得 3 分，有但一般得 1 分，无得 0 分 |
| 核心课程 | 4 | 与岗位高度相关得 4 分，部分相关得 2 分，无关或无得 0 分 |
| 奖项荣誉 | 3 | 有省级以上奖项得 3 分，有校级奖项得 2 分，无得 0 分 |

### 三、项目经历（25 分）

| 评分项 | 满分 | 评分标准 |
|-------|------|---------|
| 项目数量 | 5 | ≥3 个得 5 分，2 个得 3 分，1 个得 1 分，0 个得 0 分 |
| 技术栈说明 | 4 | 每个项目都有得 4 分，部分有得 2 分，无得 0 分 |
| STAR 结构 | 5 | 完整使用得 5 分，部分使用得 2 分，未使用得 0 分 |
| 量化成果 | 6 | 每个项目都有数字得 6 分，部分有得 3 分，无得 0 分 |
| 个人贡献 | 5 | 明确"我"的贡献得 5 分，模糊得 2 分，无得 0 分 |

### 四、实习经历（15 分）

| 评分项 | 满分 | 评分标准 |
|-------|------|---------|
| 有实习经历 | 5 | 有得 5 分，无得 0 分（应届生若无实习不扣分） |
| 基本信息 | 3 | 公司+岗位+时间完整得 3 分，不完整得 1 分 |
| 工作内容 | 4 | 有具体描述得 4 分，笼统描述得 1 分，无得 0 分 |
| 量化成果 | 3 | 有数字得 3 分，无得 0 分 |

### 五、技能特长（10 分）

| 评分项 | 满分 | 评分标准 |
|-------|------|---------|
| 分类清晰 | 3 | 分类呈现得 3 分，堆砌得 1 分，无得 0 分 |
| 熟练程度 | 3 | 标注程度得 3 分，未标注得 1 分 |
| JD 匹配 | 4 | 覆盖 80%+ JD 关键词得 4 分，60-80%得 2 分，<60%得 0 分 |

### 六、自我评价（5 分）

| 评分项 | 满分 | 评分标准 |
|-------|------|---------|
| 具体事例 | 3 | 用事例支撑得 3 分，空话得 0 分 |
| 非套话 | 2 | 有信息量得 2 分，纯套话得 0 分 |

### 七、格式规范（10 分）

| 评分项 | 满分 | 评分标准 |
|-------|------|---------|
| 页数 | 3 | 1 页得 3 分，1.5 页得 1 分，2+ 页得 0 分 |
| 错别字 | 3 | 无错误得 3 分，1-2 处得 1 分，3+ 处得 0 分 |
| 时间格式 | 2 | 统一得 2 分，不统一得 0 分 |
| 排版 | 2 | 清晰得 2 分，混乱得 0 分 |

### 八、ATS 兼容性（5 分）

| 评分项 | 满分 | 评分标准 |
|-------|------|---------|
| 格式简单 | 2 | 无复杂格式得 2 分，有表格/图片得 0 分 |
| 关键词覆盖 | 3 | ≥60%得 3 分，40-60%得 1 分，<40%得 0 分 |

---

## 等级判定

| 总分范围 | 等级 | 图标 | 建议 |
|---------|------|------|------|
| 85-100 | 优秀 | ⭐⭐⭐⭐⭐ | 可以直接投递 |
| 70-84 | 良好 | ⭐⭐⭐⭐ | 小幅优化后投递 |
| 60-69 | 及格 | ⭐⭐⭐ | 需要优化后再投递 |
| 40-59 | 较差 | ⭐⭐ | 建议大幅修改 |
| 0-39 | 不及格 | ⭐ | 建议重写 |
