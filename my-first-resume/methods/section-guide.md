# 各模块写作指南

## 模块 1：基本信息

### 必填项
- 姓名
- 电话（确保畅通）
- 邮箱（建议用专业邮箱，如 name@gmail.com）
- 求职意向（岗位 + 城市）

### 可选项
- GitHub/技术博客（技术岗必填）
- LinkedIn（外企必填）
- 个人网站/作品集（设计岗必填）

### ❌ 不要写
- 身份证号
- 家庭住址
- 婚姻状况
- 照片（除非岗位要求）

### 示例

```
张三
电话：138-xxxx-xxxx  |  邮箱：zhangsan@gmail.com
求职意向：前端开发工程师（北京）
GitHub：github.com/zhangsan  |  博客：zhangsan.dev
```

## 模块 2：教育背景

### 必填项
- 学校名称
- 专业
- 学历
- 时间范围

### 可选项（应届生建议填写）
- GPA/排名（如果优秀）
- 核心课程（选与岗位相关的）
- 奖项荣誉
- 学生干部经历

### ❌ 不要写
- 所有课程列表（太长）
- 与岗位无关的课程
- 高中及以下学历

### 示例

```
教育背景
─────────────────────────────────────
XX大学 | 计算机科学与技术 | 本科 | 2020.09 - 2024.06
• GPA：3.8/4.0，专业排名前 10%
• 核心课程：数据结构、算法设计、计算机网络、Web 开发
• 荣誉：国家奖学金（2022）、校级三好学生（2021-2023）
```

## 模块 3：项目经历（重点！）

### 写作要点
- 使用 STAR 结构
- 每个项目 3-5 个要点
- 必须量化成果
- 突出个人贡献

### 项目选择原则
1. 与目标岗位相关
2. 有一定复杂度
3. 有可量化的成果
4. 能在面试中深入讨论

### 示例

```
项目经历
─────────────────────────────────────
校园二手交易平台 | 前端负责人 | 2023.03 - 2023.06
• 技术栈：Vue.js + Vuex + Element UI + Axios
• 独立负责前端开发，实现商品浏览、购物车、订单管理 3 个核心模块
• 封装 5 个通用组件，代码复用率提升 40%
• 实现响应式布局，移动端访问占比 65%
• 项目上线 2 个月，注册用户 2000+，日均交易 50+ 笔
```

## 模块 4：实习经历

### 写作要点
- 与项目经历类似，使用 STAR 结构
- 强调在真实工作环境中的贡献
- 体现职业素养（沟通、协作、主动性）

### 示例

```
实习经历
─────────────────────────────────────
XX科技有限公司 | 前端开发实习生 | 2023.07 - 2023.10
• 参与公司官网改版，独立完成 3 个页面开发，提前 2 天交付
• 优化首屏加载性能，LCP 从 2.8s 降至 1.5s，提升 46%
• 编写组件使用文档，帮助 2 位新同事快速上手
• 参与代码评审，累计提出 15 条优化建议
```

## 模块 5：技能特长

### 写作要点
- 分类呈现（编程语言、框架、工具、软技能）
- 标注熟练程度（精通/熟练/了解）
- 与 JD 关键词呼应

### ❌ 不要写
- 所有学过的技术都列出来
- "精通"太多技术（显得不诚实）
- 与岗位无关的技能

### 示例

```
技能特长
─────────────────────────────────────
• 编程语言：JavaScript（熟练）、TypeScript（熟练）、Python（了解）
• 前端框架：Vue.js（熟练）、React（了解）、微信小程序（熟练）
• 工具链：Git、Webpack、Vite、Figma
• 其他：英语 CET-6（550）、技术博客 20 篇
```

## 模块 6：自我评价

### 写作要点
- 用具体事例支撑，不要空话
- 与岗位要求呼应
- 控制在 3-5 行

### ❌ 不要写
- "吃苦耐劳、认真负责、团队合作"（太空）
- "热爱学习、追求卓越"（没有信息量）

### 示例

```
自我评价
─────────────────────────────────────
• 对前端技术有热情，维护个人技术博客，累计输出 20 篇文章
• 具备独立开发能力，从 0 到 1 完成 3 个完整项目
• 良好的沟通协作能力，在团队项目中担任技术负责人
• 快速学习能力，2 周内从 Vue2 迁移至 Vue3 并应用于项目
```

## 模块顺序建议

### 应届生推荐顺序
1. 基本信息
2. 教育背景（应届生放前面）
3. 项目经历（重点）
4. 实习经历（如有）
5. 技能特长
6. 自我评价

### 有实习经历者推荐顺序
1. 基本信息
2. 实习经历（放前面）
3. 项目经历
4. 教育背景
5. 技能特长
6. 自我评价
