# JD 匹配分析指令

## 概述

将简历与目标岗位的 JD（职位描述）进行匹配分析，评估关键词覆盖率、能力维度匹配度，并给出优化建议。

---

## 分析步骤

### Step 1：提取 JD 关键词

从 JD 中提取以下类型的关键词：

| 类型 | 示例 |
|-----|------|
| **技术栈** | Vue.js、React、Node.js、MySQL、Redis |
| **工具** | Git、Webpack、Docker、Jenkins |
| **能力** | 沟通协作、项目管理、数据分析 |
| **经验** | 3 年经验、有大厂经历、有完整项目经验 |
| **学历** | 本科及以上、硕士优先 |
| **证书** | CPA、CFA、PMP |

### Step 2：检查简历覆盖

将 JD 关键词与简历内容进行匹配：

```
JD 关键词覆盖分析：

✅ 已覆盖（简历中出现）：
- 【关键词1】：出现在【项目经历】模块
- 【关键词2】：出现在【技能特长】模块
- 【关键词3】：出现在【项目经历】模块

⚠️ 部分覆盖（相关但不完全匹配）：
- 【关键词4】：简历中有【相关表述】，但不完全匹配
- 【关键词5】：简历中有【相关表述】，但不完全匹配

❌ 未覆盖（简历中未出现）：
- 【关键词6】
- 【关键词7】
- 【关键词8】

覆盖率：XX%
```

### Step 3：能力维度匹配

| 能力维度 | JD 要求 | 简历体现 | 匹配度 |
|---------|---------|---------|-------|
| 技术能力 | 【要求】 | 【体现】 | 高/中/低 |
| 项目经验 | 【要求】 | 【体现】 | 高/中/低 |
| 沟通协作 | 【要求】 | 【体现】 | 高/中/低 |
| 学习能力 | 【要求】 | 【体现】 | 高/中/低 |

### Step 4：给出优化建议

针对未覆盖和部分覆盖的关键词，给出具体优化建议：

```
优化建议：

【未覆盖关键词1】
- 问题：JD 要求【关键词1】，但简历中未体现
- 建议：在【项目经历】模块中，补充【具体内容】
- 示例：【示例表述】

【未覆盖关键词2】
- 问题：JD 要求【关键词2】，但简历中未体现
- 建议：在【技能特长】模块中，添加【关键词2】
- 注意：确保你确实具备该技能

【部分覆盖关键词3】
- 问题：简历中有相关表述，但不够明确
- 建议：将【原表述】改为【优化表述】
```

## 注意事项

1. **真实性**：优化建议必须基于用户真实能力，不能编造
2. **优先级**：按 JD 重要性排序优化建议
3. **可操作性**：建议要具体，给出示例表述
4. **覆盖率目标**：建议达到 70% 以上再投递
