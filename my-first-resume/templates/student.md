# 应届生/实习生简历模板

## 模板说明

本模板适用于：
- 应届毕业生
- 寻找实习机会的学生
- 首次正式写简历的求职者

| 占位符 | 说明 | 示例 |

| 【城市】 | 目标工作城市 | 北京/上海/深圳 |
| 【学校名称】 | 毕业学校 | XX大学 |

| 【项目名称】 | 项目名称 | 校园二手交易平台 |

| 【公司名称】 | 实习公司名称 | XX科技有限公司 |

## 格式要求

1. **长度**：应届生简历控制在 1 页
2. **字体**：中文用宋体/微软雅黑，英文用 Arial/Times New Roman
3. **字号**：正文 10-12pt，标题 14-16pt
4. **行距**：1.15-1.5 倍行距
5. **边距**：上下左右各 1.5-2cm
6. **格式**：导出为 PDF 投递
