# 文献查询指令（三板块）

## 查询策略

针对用户论文主题，通过 WebSearch 进行三板块并行查询。

---

## 板块1：学术论文（可直接引用）

### 查询目标

与主题直接相关的学术论文、期刊文章、学位论文。

### 查询方式

使用以下检索式进行 WebSearch：

```
"{topic}" 学术论文 期刊 研究
"{topic}" 文献综述 研究进展
"{topic}" 理论框架 实证研究
```

### 筛选标准

- 优先近5年（2020-2025）文献
- 优先核心期刊、CSSCI、SSCI、SCI
- 经典文献可放宽时间限制
- 确保文献真实存在，可查可引

### 输出格式

```
📄 学术论文板块（可直接引用）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[1] 作者. 标题[J]. 期刊名, 年份, 卷(期): 页码.
    └─ 核心观点：[一句话概括论文核心论点]
    └─ 可用位置：建议在论文哪部分引用
    └─ 可引段落：[1-2句可直接引用的内容]

[2] ...

⚠️ 验证提示：建议在学校数据库（知网/万方/Google Scholar）中核实以上文献
```

### 数量要求

- 最少5篇，最多8篇
- 确保覆盖主题的不同子方向
- 包含1-2篇经典文献（引用率高）

---

## 板块2：数据资料（提供真实数据）

### 查询目标

统计数据、调查报告、官方数据、行业数据。

### 查询方式

使用以下检索式进行 WebSearch：

```
"{topic}" 统计数据 报告 2023 2024
"{topic}" 年鉴 白皮书 官方数据
"{topic}" 调查 百分比 趋势
```

### 筛选标准

- 优先官方机构数据（统计局、部委、国际组织）
- 优先权威报告（麦肯锡、艾瑞、IDC等）
- 数据时效性：优先近3年数据
- 确保数据真实，可追溯来源

### 输出格式

```
📊 数据资料板块（提供真实数据）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📈 数据组1：{数据主题}
    └─ 数据来源：XX机构/报告名称
    └─ 数据内容：具体数值、百分比、趋势
    └─ 时间范围：20XX年
    └─ 可用位置：建议在论文哪部分使用
    └─ 引用格式：按引用规范排版

📈 数据组2：...

⚠️ 验证提示：以上数据来自公开渠道，建议核实最新版本和适用范围
```

### 数量要求

- 最少3组，最多5组
- 数据类型多样化（比例、趋势、对比）
- 确保数据与论文论点相关

---

## 板块3：思路参考（仅供借鉴）

### 查询目标

相关领域的观点、理论框架、分析角度、方法论思路。

### 查询方式

使用以下检索式进行 WebSearch：

```
"{topic}" 分析框架 视角
"{topic}" 观点 评论 讨论
"{topic}" 方法论 研究路径
```

### 筛选标准

- 优先学术博客、知名学者观点、综述文章
- 可包括非学术但权威的观点（如政策解读）
- 关注分析角度和方法论创新
- 不追求可引用性，追求启发性

### 输出格式

```
💡 思路参考板块（仅供借鉴，不可直接引用）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💡 思路1：{思路主题}
    └─ 思路来源：XX文章/书籍/观点（作者，年份）
    └─ 核心思路：[可借鉴的分析角度或论证逻辑]
    └─ 借鉴方向：[建议在论文中如何应用]
    └─ ⚠️ 注意：不可直接引用，仅作为写作思路参考

💡 思路2：...
```

### 数量要求

- 最少3条，最多5条
- 覆盖不同分析视角
- 标注不可引用的原因

---

## 三板块汇总

查询完成后，汇总为：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📚 文献查询汇总
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📄 学术论文：X篇（可直接引用）
📊 数据资料：X组（嵌入论证）
💡 思路参考：X条（仅作借鉴）

⚠️ 风险提示：
- 以上文献基于网络检索，可能存在偏差
- 建议在学校数据库中核实核心文献
- 如果您有自有文献，请提供，我将优先使用
```
