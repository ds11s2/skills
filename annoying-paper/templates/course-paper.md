# 课程论文完整模板

## 封面信息（如需要）

```
论文题目：{topic}
课程名称：{course}
学科领域：{discipline}
字数：{word_count}字
```

## 正文模板

### 摘要

{摘要内容：200-400字，四段式——背景、目的、方法、结论}

**关键词**：{3-5个关键词}

---

### 一、引言

#### 1.1 研究背景

{从宏观到微观，逐步聚焦研究主题。引用权威数据或观点支撑。2-3段。}

#### 1.2 研究目的与意义

{明确指出本文要回答的核心问题。说明理论意义和实践意义。1-2段。}

#### 1.3 研究方法/论文结构

{简述采用的分析方法。简要说明各章节安排。1段。}

---

### 二、文献综述 / 理论基础

#### 2.1 核心概念界定

{对论文涉及的关键概念进行定义。说明本文采用的概念内涵。1段。}

#### 2.2 国内外研究现状

{按时间线或主题线组织文献。每段聚焦一个子主题。引用格式："作者（年份）指出..."}

#### 2.3 理论框架

{阐述本文采用的理论视角。说明理论如何指导分析。1-2段。}

---

### 三、主体分析

#### 3.1 {dimension1}

{展开第一个分析维度。论点-论据-论证完整。适当引用文献。}

#### 3.2 {dimension2}

{展开第二个分析维度。与3.1形成递进或对比关系。}

#### 3.3 {dimension3}

{展开第三个分析维度。可包含案例分析或数据支撑。}

---

### 四、结论与建议

#### 4.1 主要结论

{概括核心发现。回应引言提出的研究问题。不重复正文细节。1-2段。}

#### 4.2 对策建议/启示

{基于结论提出具体建议。或指出对实践的启示。1段。}

#### 4.3 研究不足与展望

{诚实指出本文局限。提出未来研究方向。1段。}

---

### 参考文献

{按引用格式统一排版。仅包含板块1的学术论文 + 用户自提供文献。}

```
[1] 作者. 标题. 期刊/出版社, 年份.
[2] ...
```

## 占位符说明

| 占位符 | 含义 | 填充时机 |
|--------|------|----------|
| `{topic}` | 论文题目 | Step 0 |
| `{course}` | 课程名称 | Step 0 |
| `{discipline}` | 学科领域 | Step 0 |
| `{word_count}` | 目标字数 | Step 0 |
| `{dimension1-3}` | 主体分析维度 | Step 2（大纲生成时确定） |
