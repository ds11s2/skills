# 课程论文大纲模板

## 标准结构

```
一、引言（约{intro_pct}%篇幅，约{intro_words}字）
   1.1 研究背景
   1.2 研究目的与意义
   1.3 研究方法/论文结构

二、文献综述 / 理论基础（约{review_pct}%篇幅，约{review_words}字）
   2.1 核心概念界定
   2.2 国内外研究现状
   2.3 理论框架

三、主体分析（约{body_pct}%篇幅，约{body_words}字）
   3.1 {dimension1}
   3.2 {dimension2}
   3.3 {dimension3}

四、结论与建议（约{conclusion_pct}%篇幅，约{conclusion_words}字）
   4.1 主要结论
   4.2 对策建议/启示
   4.3 研究不足与展望

参考文献
```

## 字数分配规则

根据总字数自动分配各部分占比：

| 总字数 | 摘要 | 引言 | 文献综述 | 主体 | 结论 |
|--------|------|------|----------|------|------|
| 3000字 | 100字 | 15% | 15% | 50% | 15% |
| 5000字 | 200字 | 12% | 18% | 48% | 15% |
| 8000字 | 300字 | 12% | 18% | 45% | 15% |
| 10000字 | 400字 | 12% | 18% | 43% | 15% |

## 主体部分类型适配

根据论文主题自动选择主体结构类型：

### 类型A：理论分析型
适合：哲学、社会学、文学评论等理论性强的主题
```
3.1 理论框架阐述
3.2 理论应用分析
3.3 理论反思与拓展
```

### 类型B：案例分析型
适合：管理学、教育学、法学等需要具体案例支撑的主题
```
3.1 案例背景介绍
3.2 案例分析（多角度）
3.3 案例启示
```

### 类型C：比较分析型
适合：跨文化研究、政策比较、方法比较等主题
```
3.1 比较对象概述
3.2 维度一比较
3.3 维度二比较
3.4 比较结论
```

### 类型D：实证分析型
适合：经济学、心理学、传播学等需要数据分析的主题
```
3.1 数据来源与说明
3.2 数据分析
3.3 结果讨论
```

### 类型E：问题-对策型
适合：公共政策、社会治理、教育改革等应用性主题
```
3.1 问题现状分析
3.2 问题成因探究
3.3 对策建议
```
