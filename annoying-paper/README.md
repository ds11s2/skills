# annoying-paper Skill 构建文档

> 大学生通识课/选修课快捷论文生成器

## 项目概述

`annoying-paper` 是一个面向大学生通识课、选修课课程论文写作的 AI Skill。通过多角色决策团队评审、量化评分、多轮校验修改，一次性输出高质量课程论文。

## 核心特性

- ⚡ **一次性输出**：不渐进引导，直接生成完整论文
- 🎭 **多角色评审**：5角色决策团队独立评审，模拟真实审稿
- 📊 **量化评分**：100分制严格评分，不达标自动修复
- 🔄 **多轮校验**：评分<85分自动进入修复循环，最多3轮
- 📚 **三板块文献**：学术论文/数据资料/思路参考，分类查询
- 📄 **三格式导出**：支持 docx / md / tex 格式输出

## 工作流

```
Step 0: 信息收集与课程要求确认
Step 1: 文献查询（三板块并行）
Step 2: 大纲生成
Step 3: 全文生成
Step 4: 多角色评审（100分制）
Step 5: 修复循环（条件触发，最多3轮）
Step 6: 导出（docx / md / tex）
```

## 五角色评审团队

| 角色 | 身份 | 权重 | 关注点 |
|------|------|------|--------|
| 🎓 学科导师 | 领域教授 | 25% | 学术准确性、理论深度、论证逻辑 |
| 📝 写作教练 | 写作专家 | 20% | 语言规范、结构清晰度 |
| 🔍 文献审查员 | 期刊审稿人 | 20% | 引用规范、文献相关性 |
| 📊 数据审计师 | 数据专家 | 20% | 数据准确性、来源可靠性 |
| 👨‍🎓 学生代表 | 同课程学长 | 15% | 可读性、篇幅适配、课程匹配 |

## 评分等级

| 总分 | 等级 | 处理 |
|------|------|------|
| ≥ 85 | ✅ 优秀 | 直接进入导出 |
| 70-84 | ⚠️ 良好 | 进入修复循环 |
| < 70 | ❌ 不合格 | 进入修复循环（最多3轮） |

## 三板块文献查询

1. **📄 学术论文** → 直接引用，写入参考文献
2. **📊 数据资料** → 嵌入正文论证
3. **💡 思路参考** → 仅借鉴，不引用

## 导出格式

| 格式 | 说明 |
|------|------|
| docx | 标准Word文档 |
| md | Markdown格式 |
| tex | LaTeX格式（自动检索学科模板） |

## 注意事项

- 生成内容仅供参考，需自行核实引用文献和数据
- 建议优先使用自有文献，提高引用可靠性
- 最终提交前请进行个性化修改

## 与 my-first-resume 对比

| 维度 | my-first-resume | annoying-paper |
|------|----------------|----------------|
| 交互模式 | 渐进式引导（8步） | 一次性输出（7步） |
| 评审机制 | 5角色批判 + 模拟投递 | 5角色评审 + 量化评分 |
| 修复机制 | 手动迭代 | 自动修复循环 |
| 输出格式 | HTML/PDF | docx/md/tex |
| 核心特色 | STAR润色、模拟投递 | 三板块文献、降AI痕迹 |
