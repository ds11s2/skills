# 量化评分标准（100分制）

## 评分汇总公式

```
总分 = 学科导师得分 × 25% + 写作教练得分 × 20% + 文献审查员得分 × 20% + 数据审计师得分 × 20% + 学生代表得分 × 15%
```

---

## 角色1：学科导师（25分）

| 评分项 | 满分 | 评分标准 | 得分 |
|--------|------|----------|------|
| **学术准确性** | 10分 | 概念使用正确、理论引用准确、无常识性错误、术语规范 | |
| **理论深度** | 8分 | 有明确理论框架、分析有层次、理论联系实际、有独立见解 | |
| **论证逻辑** | 7分 | 论点-论据-结论完整、无逻辑跳跃、论证充分、结论自然推出 | |
| **小计** | **25分** | | |

### 学术准确性评分细则

| 得分 | 标准 |
|------|------|
| 9-10 | 概念使用精准，理论引用无误，术语完全符合学科规范 |
| 7-8 | 概念基本正确，偶有轻微不准确，术语使用大体规范 |
| 5-6 | 存在若干概念误用，理论引用有偏差，术语使用不规范 |
| 3-4 | 概念错误较多，理论引用明显有误 |
| 0-2 | 存在严重学术错误，基本学术规范未达标 |

### 理论深度评分细则

| 得分 | 标准 |
|------|------|
| 7-8 | 理论框架清晰，分析深入多层，理论与现实结合紧密，有独到见解 |
| 5-6 | 有理论框架，分析有一定深度，能联系实际，见解较常规 |
| 3-4 | 理论框架模糊，分析流于表面，理论与实际脱节 |
| 0-2 | 缺乏理论框架，纯描述性内容 |

### 论证逻辑评分细则

| 得分 | 标准 |
|------|------|
| 6-7 | 逻辑链条完整严密，论证充分无遗漏，结论自然合理 |
| 4-5 | 逻辑基本通顺，偶有跳跃，论证大体充分 |
| 2-3 | 逻辑存在明显断裂，论证薄弱，结论牵强 |
| 0-1 | 逻辑混乱，论证严重不足 |

## 角色2：写作教练（20分）

| 评分项 | 满分 | 评分标准 | 得分 |
|--------|------|----------|------|
| **语言规范** | 8分 | 无口语化、用词准确专业、句式多样、无语法错误 | |
| **结构清晰度** | 7分 | 章节层次分明、比例合理、过渡自然、无重复 | |
| **表达流畅度** | 5分 | 段落连贯、无生硬拼接、读感自然、无明显AI痕迹 | |
| **小计** | **20分** | | |

### 语言规范评分细则

| 得分 | 标准 |
|------|------|
| 7-8 | 语言完全学术化，用词精准，句式丰富，零语法错误 |
| 5-6 | 语言基本规范，偶有口语化，用词大体准确 |
| 3-4 | 口语化表达较多，用词不够精准，存在语法问题 |
| 0-2 | 语言不规范，口语化严重，语法错误频繁 |

### 结构清晰度评分细则

| 得分 | 标准 |
|------|------|
| 6-7 | 结构完美，层次清晰，比例恰当，过渡流畅 |
| 4-5 | 结构合理，层次基本清晰，偶有比例失调 |
| 2-3 | 结构混乱，层次不清，比例严重失调 |
| 0-1 | 缺乏基本结构 |

### 表达流畅度评分细则

| 得分 | 标准 |
|------|------|
| 4-5 | 表达极为流畅，段落衔接自然，完全无AI痕迹 |
| 3 | 表达流畅，偶有生硬，AI痕迹轻微 |
| 1-2 | 表达生硬，拼接感明显，AI痕迹较重 |
| 0 | 表达极不自然，明显的AI生成特征 |

## 角色3：文献审查员（20分）

| 评分项 | 满分 | 评分标准 | 得分 |
|--------|------|----------|------|
| **引用规范性** | 8分 | 格式统一、信息完整、内外对应、符合指定格式 | |
| **文献相关性** | 7分 | 文献与论点相关、无凑数、选择合理、密度适中 | |
| **引用充分性** | 5分 | 核心论点有支撑、数量充足、观点有来源 | |
| **小计** | **20分** | | |

### 引用规范性评分细则

| 得分 | 标准 |
|------|------|
| 7-8 | 引用格式完全统一，信息完整无误，内外一一对应 |
| 5-6 | 引用格式基本统一，偶有信息缺失，内外大体对应 |
| 3-4 | 引用格式混乱，信息缺失较多，内外不对应 |
| 0-2 | 引用格式严重错误，基本规范未达标 |

### 文献相关性评分细则

| 得分 | 标准 |
|------|------|
| 6-7 | 每篇文献都与论点紧密相关，经典与前沿搭配合理 |
| 4-5 | 文献大体相关，偶有凑数，选择基本合理 |
| 2-3 | 文献相关性差，凑数明显，选择不当 |
| 0-1 | 文献与主题几乎无关 |

### 引用充分性评分细则

| 得分 | 标准 |
|------|------|
| 4-5 | 所有核心论点都有文献支撑，数量充足，无观点遗漏 |
| 3 | 大部分论点有支撑，数量基本达标 |
| 1-2 | 多处论点无支撑，数量不足 |
| 0 | 几乎无文献支撑 |

## 角色4：数据审计师（20分）

| 评分项 | 满分 | 评分标准 | 得分 |
|--------|------|----------|------|
| **数据准确性** | 8分 | 数据与来源一致、无编造、计算正确、时效合理 | |
| **来源可靠性** | 7分 | 来源权威、来自官方/学术渠道、无不可靠来源 | |
| **论证支撑度** | 5分 | 数据有效支撑论点、无堆砌、解读合理、关联清晰 | |
| **小计** | **20分** | | |

### 数据准确性评分细则

| 得分 | 标准 |
|------|------|
| 7-8 | 所有数据准确无误，与来源完全一致，计算正确 |
| 5-6 | 数据基本准确，偶有微小偏差 |
| 3-4 | 数据存在明显错误，或有编造嫌疑 |
| 0-2 | 数据严重失实，大量编造 |

### 来源可靠性评分细则

| 得分 | 标准 |
|------|------|
| 6-7 | 所有数据来自权威官方机构或学术文献 |
| 4-5 | 大部分来源可靠，偶有一般性来源 |
| 2-3 | 来源可靠性差，有自媒体等不可靠来源 |
| 0-1 | 数据来源不明或完全不可靠 |

### 论证支撑度评分细则

| 得分 | 标准 |
|------|------|
| 4-5 | 数据精准支撑论点，解读深入，关联清晰 |
| 3 | 数据大体支撑论点，解读基本合理 |
| 1-2 | 数据堆砌，与论点关联弱 |
| 0 | 数据与论点无关 |

## 角色5：学生代表（15分）

| 评分项 | 满分 | 评分标准 | 得分 |
|--------|------|----------|------|
| **可读性** | 5分 | 语句通顺、逻辑清晰、不晦涩、非专业读者能理解 | |
| **篇幅适配度** | 5分 | 字数符合要求（偏差≤10%）、各部分比例合理 | |
| **课程匹配度** | 5分 | 符合课程论文定位、难度适中、回应核心议题 | |
| **小计** | **15分** | | |

### 可读性评分细则

| 得分 | 标准 |
|------|------|
| 4-5 | 表达清晰流畅，逻辑一目了然，完全易懂 |
| 3 | 大体可读，偶有晦涩之处 |
| 1-2 | 多处晦涩难懂，逻辑不清 |
| 0 | 几乎无法理解 |

### 篇幅适配度评分细则

| 得分 | 标准 |
|------|------|
| 4-5 | 字数精准符合要求（偏差≤5%），各部分比例完美 |
| 3 | 字数基本符合（偏差≤10%），比例大体合理 |
| 1-2 | 字数偏差>10%，或比例严重失调 |
| 0 | 字数严重不足或超额 |

### 课程匹配度评分细则

| 得分 | 标准 |
|------|------|
| 4-5 | 完美匹配课程要求，难度恰当，深度回应课程议题 |
| 3 | 基本匹配，难度略偏，能回应主要议题 |
| 1-2 | 匹配度差，难度明显不当，偏离课程议题 |
| 0 | 完全不符合课程要求 |

## 评分等级判定

| 总分 | 等级 | 处理建议 |
|------|------|----------|
| 90-100 | 🌟 卓越 | 质量极高，可直接导出 |
| 85-89 | ✅ 优秀 | 质量良好，可直接导出 |
| 80-84 | ⚠️ 良好 | 有小问题，建议修复1轮 |
| 70-79 | 🔧 合格 | 有明显问题，必须修复 |
| < 70 | ❌ 不合格 | 问题严重，需大幅修改 |

## 修复优先级映射

| 得分区间 | 高优先级问题 | 中优先级问题 | 低优先级问题 |
|----------|-------------|-------------|-------------|
| 80-84 | 引用错误、数据错误 | 语言不规范 | 表达优化 |
| 70-79 | 引用错误、数据错误、逻辑矛盾 | 语言不规范、结构不清 | 表达优化、过渡优化 |
| < 70 | 引用错误、数据错误、逻辑矛盾、字数偏差>10% | 语言不规范、结构不清、论证薄弱 | 表达优化、过渡优化、格式微调 |
