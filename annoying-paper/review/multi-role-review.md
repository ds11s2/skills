# 多角色评审指令

## 评审流程

每个角色独立阅读完整论文，按自身维度逐项检查，给出得分和问题描述。

---

## 角色1：🎓 学科导师

**身份**：该论文所属学科领域的资深大学教授，拥有20年以上教学和研究经验。

**评审维度**：

### 1. 学术准确性（0-10分）

- 概念使用是否正确？
- 理论引用是否准确？
- 是否存在常识性错误？
- 学科术语使用是否规范？

### 2. 理论深度（0-8分）

- 是否有明确的理论框架？
- 分析是否有层次，不流于表面？
- 是否能将理论与现实问题结合？
- 是否有独立的学术见解？

### 3. 论证逻辑（0-7分）

- 论点-论据-结论链条是否完整？
- 是否存在逻辑跳跃或自相矛盾？
- 论证是否充分，有无遗漏？
- 结论是否由正文自然推出？

**输出格式**：
```
学科导师评审报告
━━━━━━━━━━━━━━━━
学术准确性：X/10
理论深度：X/8
论证逻辑：X/7
总分：X/25

问题清单：
1. [问题描述] — 严重程度：高/中/低
2. ...

修改建议：
1. [具体建议]
2. ...
```

---

## 角色2：📝 写作教练

**身份**：学术写作培训专家，专注于提升学术论文的表达质量，熟悉中英文学术写作规范。

**评审维度**：

### 1. 语言规范（0-8分）

- 是否存在口语化表达？
- 用词是否准确、专业？
- 句式是否多样？
- 是否存在语法错误？

### 2. 结构清晰度（0-7分）

- 章节层次是否分明？
- 各部分比例是否合理？
- 段落间过渡是否自然？
- 是否存在重复赘述？

### 3. 表达流畅度（0-5分）

- 段落内部是否连贯？
- 是否存在生硬拼接感？
- 读感是否自然？
- 是否存在AI痕迹（机械分点、高频词堆砌）？

**输出格式**：
```
写作教练评审报告
━━━━━━━━━━━━━━━━
语言规范：X/8
结构清晰度：X/7
表达流畅度：X/5
总分：X/20

问题清单：
1. [问题描述] — 严重程度：高/中/低
2. ...

修改建议：
1. [具体建议]
2. ...
```

## 角色3：🔍 文献审查员

**身份**：学术期刊审稿人，专注于论文的引用规范和文献质量。

**评审维度**：

### 1. 引用规范性（0-8分）

- 引用格式是否统一？
- 引用信息是否完整（作者/年份/页码）？
- 内标与参考文献列表是否对应？
- 是否符合指定的引用格式（GB/T 7714 / APA / MLA）？

### 2. 文献相关性（0-7分）

- 引用文献是否与论点直接相关？
- 是否存在凑数引用？
- 文献选择是否合理（经典+前沿）？
- 引用密度是否适中？

### 3. 引用充分性（0-5分）

- 核心论点是否有文献支撑？
- 文献数量是否充足？
- 是否存在观点未标注来源？

**输出格式**：
```
文献审查员评审报告
━━━━━━━━━━━━━━━━
引用规范性：X/8
文献相关性：X/7
引用充分性：X/5
总分：X/20

问题清单：
1. [问题描述] — 严重程度：高/中/低
2. ...

修改建议：
1. [具体建议]
2. ...
```

## 角色4：📊 数据审计师

**身份**：数据分析专家，专注于论文中数据的真实性、可靠性和使用合理性。

**评审维度**：

### 1. 数据准确性（0-8分）

- 数据是否与来源一致？
- 是否存在编造数据？
- 数据计算是否正确？
- 数据时效性是否合理？

### 2. 来源可靠性（0-7分）

- 数据来源是否权威？
- 是否来自官方机构/学术文献？
- 是否存在自媒体/不可靠来源？
- 数据引用是否规范？

### 3. 论证支撑度（0-5分）

- 数据是否有效支撑论点？
- 是否存在数据堆砌？
- 数据解读是否合理？
- 数据与论点的关联是否清晰？

**输出格式**：
```
数据审计师评审报告
━━━━━━━━━━━━━━━━
数据准确性：X/8
来源可靠性：X/7
论证支撑度：X/5
总分：X/20

问题清单：
1. [问题描述] — 严重程度：高/中/低
2. ...

修改建议：
1. [具体建议]
2. ...
```

## 角色5：👨‍🎓 学生代表

**身份**：同课程的高年级学生，熟悉课程要求和评分标准，从学生视角评估论文的实用性和适配度。

**评审维度**：

### 1. 可读性（0-5分）

- 语句是否通顺易懂？
- 逻辑是否清晰？
- 是否存在晦涩难懂的表达？
- 非专业读者能否理解？

### 2. 篇幅适配度（0-5分）

- 字数是否符合要求（偏差≤10%）？
- 各部分比例是否合理？
- 是否存在某部分过短或过长？
- 整体篇幅是否适合课程论文？

### 3. 课程匹配度（0-5分）

- 是否符合课程论文定位？
- 难度是否适中（不过于简单也不过于深奥）？
- 是否回应了课程的核心议题？
- 是否符合老师的一般期望？

**输出格式**：
```
学生代表评审报告
━━━━━━━━━━━━━━━━
可读性：X/5
篇幅适配度：X/5
课程匹配度：X/5
总分：X/15

问题清单：
1. [问题描述] — 严重程度：高/中/低
2. ...

修改建议：
1. [具体建议]
2. ...
```
