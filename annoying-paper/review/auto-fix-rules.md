# 自动修复规则

## 修复流程

1. 读取评审报告，提取所有问题
2. 按优先级分类问题
3. 逐项修复
4. 修复后重新评审

---

## 优先级定义

### 🔴 高优先级（必须修复）

触发条件：
- 引用错误（格式错误、信息缺失、内外不对应）
- 数据错误（与来源不一致、编造数据）
- 逻辑矛盾（前后观点冲突、结论与论证不符）
- 字数偏差 > 10%
- 学术错误（概念误用、理论引用错误）

**修复策略**：
- 引用错误 → 核对原文，修正格式，补充缺失信息
- 数据错误 → 重新检索验证，替换为准确数据，或标注"需核实"
- 逻辑矛盾 → 重新梳理论证链条，删除矛盾内容，补充过渡
- 字数偏差 → 扩展或压缩相应章节，保持比例
- 学术错误 → 查阅权威资料，修正概念和理论表述

---

### 🟡 中优先级（应当修复）

触发条件：
- 语言不规范（口语化表达、主观表述）
- 结构不清晰（层次混乱、比例失调）
- 论证薄弱（论点缺乏支撑、论据不足）
- 文献相关性差（凑数引用、与论点无关）
- AI痕迹明显（机械分点、高频词堆砌）

**修复策略**：
- 语言不规范 → 按 `methods/writing-principles.md` 改写为学术语言
- 结构不清晰 → 调整章节顺序，补充过渡段落，重新分配字数
- 论证薄弱 → 补充文献支撑，增加数据分析，深化论证
- 文献相关性差 → 替换为相关文献，删除凑数引用
- AI痕迹明显 → 按 `methods/anti-detection.md` 改写，避免机械分点

---

### 🟢 低优先级（建议修复）

触发条件：
- 表达优化（句式单调、用词重复）
- 过渡优化（段落衔接生硬）
- 格式微调（标点、缩进、行距）
- 结论模板化

**修复策略**：
- 表达优化 → 替换同义词，调整句式结构
- 过渡优化 → 添加过渡句，使用更自然的衔接词
- 格式微调 → 统一标点，调整段落间距
- 结论模板化 → 按 `methods/anti-detection.md` 个性化改写

---

## 修复顺序

```
Step 1: 修复所有高优先级问题
Step 2: 修复所有中优先级问题
Step 3: 修复低优先级问题（如时间允许）
Step 4: 通读全文，检查修复是否引入新问题
Step 5: 重新进入评审流程
```

## 修复记录格式

每次修复后记录：

```
修复轮次：第X轮
修复前总分：XX/100
修复问题数：高优先级X个，中优先级X个，低优先级X个

修复详情：
1. [问题描述] → [修复动作] → [修复结果]
2. ...

修复后预估：
- 学科导师：预计提升X分（原因：...）
- 写作教练：预计提升X分（原因：...）
- ...
```

## 终止条件

修复循环在以下情况终止：

1. **达标终止**：总分 ≥ 85分
2. **轮次终止**：已完成3轮修复
3. **收敛终止**：连续两轮评分提升 < 3分（认为已收敛）

终止后取所有版本中**最高分版本**作为最终输出。
