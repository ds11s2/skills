# 学术写作原则

## 一、语言规范

### 1.1 避免口语化

| 口语化表达 | 学术化改写 |
|-----------|-----------|
| 我觉得 | 研究表明 / 数据显示 |
| 很多 | 大量 / 显著 / 普遍 |
| 效果好 | 显著提升 / 有效改善 |
| 问题很大 | 问题突出 / 矛盾尖锐 |
| 说白了 | 换言之 / 本质上 |
| 挺重要的 | 至关重要 / 具有关键意义 |

### 1.2 避免主观表述

- ❌ "我认为..." "笔者认为..."
- ✅ "研究表明..." "数据分析显示..." "现有文献指出..."

- ❌ "我们发现了..."
- ✅ "本研究发现了..." "结果显示..."

### 1.3 精确用词

- 使用学科专业术语
- 避免模糊词："可能""大概""差不多" → 改用数据或文献支撑
- 量化描述："大部分" → "约70%"

## 二、逻辑论证

### 2.1 段落结构（PEEL法则）

- **P**oint（论点）：段落首句明确论点
- **E**vidence（证据）：提供数据、案例、文献支撑
- **E**xplanation（解释）：分析证据与论点的关系
- **L**ink（衔接）：结尾句过渡到下一论点

### 2.2 论证方式

优先使用以下自然过渡的论证方式：

1. **因果链条**："由于A，导致B，进而引发C..."
2. **对比分析**："与X相比，Y在Z方面表现出显著差异..."
3. **递进深入**："不仅...更重要的是..."
4. **问题-解决**："面对A问题，B提出了C方案..."
5. **案例嵌入**："以XX为例，可以清晰地看到..."

**避免机械分点**：
- ❌ "第一...第二...第三..."
- ❌ "首先...其次...最后..."
- ✅ 改用上述自然过渡方式，或将分点融入段落论述

### 2.3 过渡衔接

常用过渡词/句：

| 功能 | 表达 |
|------|------|
| 递进 | 不仅如此、更重要的是、进一步而言 |
| 转折 | 然而、值得注意的是、与此形成对比的是 |
| 因果 | 因此、由此可知、这导致 |
| 总结 | 综上所述、总体而言、由此可见 |
| 举例 | 例如、以...为例、具体而言 |

## 三、引用规范

### 3.1 引用方式

1. **直接引用**：原文照抄，加引号，标注页码
   - "..."（作者，年份：页码）

2. **间接引用/转述**：用自己的话概括，不加引号
   - 作者（年份）指出... / 研究表明（作者，年份）...

3. **观点引用**：引用某作者的观点
   - 正如作者（年份）所言...

### 3.2 引用密度

- 引言：每100字约1-2处引用
- 文献综述：每100字约2-3处引用
- 主体分析：每100字约1-2处引用
- 结论：尽量减少引用，以总结为主

## 四、常见错误清单

### 4.1 结构错误

- [ ] 缺少摘要或关键词
- [ ] 引言过于冗长，迟迟不进入主题
- [ ] 文献综述变成文献列表，缺乏评述
- [ ] 主体部分缺乏明确论点
- [ ] 结论引入新观点

### 4.2 语言错误

- [ ] 口语化表达过多
- [ ] 主观表述（"我觉得""我认为"）
- [ ] 模糊词汇（"很多""大概""可能"）
- [ ] 句子过长（超过40字）或过短（少于10字）
- [ ] 段落过长（超过300字）或过短（少于50字）

### 4.3 引用错误

- [ ] 引用格式不统一
- [ ] 内标与参考文献列表不对应
- [ ] 引用信息缺失（缺页码、缺卷号等）
- [ ] 过度引用（一段话引用3处以上）
- [ ] 引用与论点无关
