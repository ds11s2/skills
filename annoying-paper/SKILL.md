# annoying-paper

## 适用场景

- 大学生需要完成通识课、选修课、公共课的课程论文
- 论文主题涉及非本专业领域，学生不熟悉该学科
- 追求快捷便利，希望一次性获得完整论文
- 课程论文字数通常在 3000-10000 字

## 核心工作流

### Step 0: 信息收集与课程要求确认

**目的**：一次性收集论文主题、课程要求、格式偏好等所有信息。

**执行步骤**：

1. **展示信息收集表单**，要求用户填写以下字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| `topic` | 是 | 论文题目或主题 |
| `course` | 是 | 课程名称 |
| `word_count` | 是 | 目标字数 |
| `discipline` | 是 | 论文所属学科领域 |
| `requirements` | 否 | 课程特殊要求（如"需包含案例分析"） |
| `user_refs` | 否 | 用户自有的参考文献 |

2. **主动索要课程论文要求**：如果用户未提供 `requirements`，必须追问：
   > "请提供该课程对论文的具体要求，例如：格式规范（APA/GB/T 7714/MLA）、是否需要摘要/关键词、是否有特定章节要求、评分标准等。这些信息将帮助我生成更贴合要求的论文。"

3. **展示风险提示**（引用 `search/risk-notice.md`）：
   > ⚠️ **使用须知**：
   > - 本工具生成的参考文献基于网络公开信息，**可能存在偏差或不可验证的情况**
   > - 建议您**优先使用学校数据库（如知网、万方）自行检索核心文献**
   > - 如果您手头已有相关参考文献，**强烈建议提供给我**，我会优先使用您的文献，确保引用真实可靠
   > - 生成内容仅供参考，**请务必自行核实关键数据和引用**

**输出**：结构化的论文需求卡片

---

### Step 1: 文献查询（三板块并行）

**目的**：为论文收集三类不同性质的参考资料。

**执行步骤**：

通过 WebSearch 进行三板块查询（引用 `search/literature-search.md`）：

#### 板块1：学术论文（可直接引用）

- **查询目标**：与主题直接相关的学术论文、期刊文章
- **输出格式**：
  ```
  [1] 作者. 标题. 期刊名, 年份, 卷(期): 页码.
      └─ 核心观点：一句话概括
      └─ 可用段落：引言/方法/结论中的可引用内容
  ```
- **数量**：5-8篇
- **用途**：直接写入论文参考文献列表，在正文中引用

#### 板块2：数据资料（提供真实数据）

- **查询目标**：统计数据、调查报告、官方数据
- **输出格式**：
  ```
  📊 数据来源：XX机构/报告名称
      └─ 数据内容：具体数值、百分比、趋势
      └─ 时间范围：20XX年
      └─ 可用位置：建议在论文哪部分使用
  ```
- **数量**：3-5组
- **用途**：嵌入正文论证，增强说服力

#### 板块3：思路参考（仅供借鉴）

- **查询目标**：相关领域的观点、理论框架、分析角度
- **输出格式**：
  ```
  💡 思路来源：XX文章/书籍/观点
      └─ 核心思路：可借鉴的分析角度或论证逻辑
      └─ ⚠️ 注意：不可直接引用，仅作为写作思路参考
  ```
- **数量**：3-5条
- **用途**：启发论证角度，**不写入参考文献**

**输出**：三板块文献汇总表

---

### Step 2: 大纲生成

**目的**：基于文献和需求生成论文大纲。

**执行步骤**：
1. 读取 `templates/outline-template.md`
2. 结合用户需求 + 文献查询结果，生成大纲
3. 大纲结构（适配课程论文）：

```
一、引言（约X%篇幅）
   1.1 研究背景
   1.2 研究目的与意义
   1.3 研究方法/论文结构

二、文献综述 / 理论基础（约X%篇幅）
   2.1 核心概念界定
   2.2 国内外研究现状
   2.3 理论框架

三、主体分析（约X%篇幅）
   3.1 [具体分析维度1]
   3.2 [具体分析维度2]
   3.3 [具体分析维度3/案例分析]

四、结论与建议（约X%篇幅）
   4.1 主要结论
   4.2 对策建议/启示
   4.3 研究不足与展望

参考文献
```

4. 根据用户 `word_count` 自动分配各部分字数占比
5. **直接展示大纲**，不要求用户逐步确认

**输出**：含字数分配的完整大纲

---

### Step 3: 全文生成

**目的**：一次性生成完整论文。

**执行步骤**：
1. 读取 `methods/paper-structure.md` + `methods/writing-principles.md` + `methods/anti-detection.md`
2. 读取 `templates/course-paper.md`
3. 按大纲结构，**逐章节生成**完整正文
4. 生成过程中：
   - 将板块1的学术论文嵌入引用（`[1]` 标注）
   - 将板块2的数据嵌入论证
   - 借鉴板块3的思路组织论证逻辑
   - 应用 `anti-detection.md` 中的降AI痕迹策略
5. 生成参考文献列表（仅含板块1的学术论文 + 用户自提供文献）
6. 按用户选择的引用格式排版

**输出**：完整论文 MD 文件

---

### Step 4: 多角色评审

**目的**：5个独立角色从不同维度严格评审论文质量。

**执行步骤**：
1. 读取 `review/multi-role-review.md` + `review/scoring-rubric.md`
2. 启动5个评审角色（**并行评审，独立打分**）：

| # | 角色 | 身份 | 评审维度 | 权重 |
|---|------|------|----------|------|
| 1 | 🎓 **学科导师** | 该领域的大学教授 | 学术准确性、理论深度、论证逻辑 | 25% |
| 2 | 📝 **写作教练** | 学术写作培训专家 | 语言规范、结构清晰度、表达流畅度 | 20% |
| 3 | 🔍 **文献审查员** | 学术期刊审稿人 | 引用规范性、文献相关性、引用充分性 | 20% |
| 4 | 📊 **数据审计师** | 数据分析专家 | 数据准确性、数据来源可靠性、论证支撑度 | 20% |
| 5 | 👨‍🎓 **学生代表** | 同课程的高年级学生 | 可读性、篇幅适配度、课程要求匹配度 | 15% |

3. 每个角色独立执行：阅读论文 → 按维度逐项检查 → 给出各项得分 → 给出问题描述 → 给出修改建议
4. 汇总总分：

```
总分 = 学科导师×25% + 写作教练×20% + 文献审查员×20% + 数据审计师×20% + 学生代表×15%
```

5. 评分等级：

| 总分 | 等级 | 处理 |
|------|------|------|
| ≥ 85 | ✅ 优秀 | 直接进入导出 |
| 70-84 | ⚠️ 良好 | 进入修复循环（1轮） |
| < 70 | ❌ 不合格 | 进入修复循环（最多3轮） |

**输出**：评审报告（含各角色独立评分 + 总分 + 问题清单 + 修改建议）

---

### Step 5: 修复循环（条件触发）

**目的**：根据评审意见自动修复论文，直到达标或达到最大轮数。

**触发条件**：总分 < 85

**执行步骤**：
1. 读取 `review/auto-fix-rules.md`
2. 按优先级排序问题清单：
   - **高优先级**（必须修复）：引用错误、数据错误、逻辑矛盾、字数偏差>10%
   - **中优先级**（应当修复）：语言不规范、结构不清晰、论证薄弱
   - **低优先级**（建议修复）：表达优化、过渡优化、格式微调
3. 逐项修复
4. 修复完成后，**重新进入 Step 4 评审**
5. 循环最多3轮，取最高分版本

**输出**：修复后的论文 + 新一轮评审报告

---

### Step 6: 导出

**目的**：按用户选择的格式输出最终论文。

**执行步骤**：
1. 展示最终论文 MD 预览
2. 询问用户导出格式：

| 选项 | 格式 | 说明 |
|------|------|------|
| A | **docx** | 标准Word文档格式 |
| B | **md** | Markdown格式，适合在线提交 |
| C | **tex** | LaTeX格式，适合理工科论文 |

3. **如果选择 tex**：
   - 通过 WebSearch 检索该学科的 LaTeX 论文模板
   - 将生成的论文内容适配到模板中
   - 确保模板包含正确的导言区、章节结构、引用格式
4. 根据用户选择生成对应格式文件
5. 输出文件到用户工作区

**输出**：最终论文文件（.docx / .md / .tex）

## 约束规则

1. **禁止编造数据**：所有数据必须有可追溯的公开来源，无法查证的数据必须标注"需核实"
2. **引用真实性**：参考文献必须基于真实检索结果，不得凭空编造
3. **字数严格**：最终输出字数与用户要求的偏差不超过 ±10%
4. **格式统一**：全文引用格式必须统一，内标与参考文献列表一一对应
5. **修复上限**：评审-修复循环最多3轮，避免无限循环
6. **用户优先**：用户提供的参考文献优先于AI检索的文献
7. **快捷优先**：在保证质量的前提下，尽量减少用户交互步骤
8. **避免分点堆砌**：论证时避免"第一...第二...第三..."的机械分点，改用连贯的段落论述、因果链条、对比分析等自然过渡方式
