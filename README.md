# Skills 集合项目

这是一个技能（Skill）集合项目，包含多个可复用的技能模块，用于扩展 Agent 的功能。

## 项目结构

```
skills/
├── LICENSE                    # 许可证文件
├── README.md                  # 项目说明文档
└── my-first-resume/           # 简历辅助技能
    ├── SKILL.md              # 技能入口文件
    ├── README.md             # 技能详细文档
    ├── methods/              # 方法论指南
    ├── templates/            # 简历模板
    ├── review/               # 评审规则
    ├── simulation/           # 模拟投递
    └── examples/             # 示例文件
```

## 技能列表

| 技能名称 | 描述 | 状态 |
|---------|------|------|
| `my-first-resume` | 面向应届生/实习生的简历辅助 Skill，通过渐进式引导、STAR 润色、多角色批判、模拟投递等环节，帮助首次写简历的用户生成高质量简历。 | ✅ 可用 |

## 使用方式

当用户说出特定触发词时，Agent 会自动激活对应的技能：

- **my-first-resume**："帮我写简历"、"我第一次写简历"、"我是应届生，需要写简历"、"帮我优化简历"
